# BOX — הורדות

אפליקציית הנדל״ן לשולחן העבודה. כל הגרסאות, לחלונות ולמק.

### [⬇ להורדת הגרסה האחרונה](../../releases/latest)

| | |
|---|---|
| **חלונות — התקנה** | `BOX-Setup-<גרסה>.exe` — מתקין את BOX ומוסיף קיצור דרך |
| **חלונות — נייד** | `BOX-Portable-<גרסה>.exe` — רץ בלי התקנה, גם מדיסק און קי |
| **מק — Apple Silicon** | `BOX-<גרסה>-mac-arm64.zip` — M1 ואילך |
| **מק — Intel** | `BOX-<גרסה>-mac-x64.zip` |

## התקנה במק

הגרסה למק אינה חתומה על ידי Apple, ולכן macOS יחסום אותה בפתיחה ראשונה.
בתוך הזיפ יש `Install BOX.command` — הרצה אחת שלו פותרת את זה. לחיצה כפולה עליו,
ואז BOX נפתח כרגיל.
